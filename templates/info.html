About SEK Currency Dashboard

Explore exchange rates, compare currencies, and discover how the Swedish krona has changed over time.

Project Overview

SEK Currency Dashboard is a web application built with Python and Flask. It allows users to compare the Swedish krona (SEK) against EUR, USD, GBP, NOK and DKK.

SEK is always the base currency. Users can enter an amount in SEK, select one or more currencies, and explore current and historical exchange rates using interactive charts.

Features

Currency Comparison

Compare SEK with one or more supported currencies.

Currency Conversion

See how much your selected SEK amount is worth in other currencies.

Historical Exchange Rates

Explore exchange rate trends over the past 12 months.

Interactive Charts

Switch between line and bar charts and explore Day, Week, Month and Quarter groupings.

Analysis Guide

Follow these instructions to answer the three analysis questions using the dashboard.

QUESTION 01

How has the value of SEK in EUR changed over the last 12 months?

  1. Enter 1 in the SEK amount field.
  2. Select EUR and click Submit.
  3. Examine the historical line chart.
  4. Compare the beginning and end of the line to determine whether SEK increased or decreased in value against EUR.
QUESTION 02

Against which of the five currencies has SEK strengthened or weakened the most over the past year?

  1. Enter 1 in the SEK amount field.
  2. Select all five currencies and click Submit.
  3. Click Switch Chart to display the percentage change bar chart.
  4. Compare the percentage changes. The highest value shows where SEK strengthened the most, while the lowest shows where it weakened the most.
QUESTION 03

In which of the five currencies has 1 SEK had the highest numerical exchange value during the last 12 months?

  1. Enter 1 in the SEK amount field.
  2. Select all five currencies and click Submit.
  3. Use the line chart with Day selected for the most detailed view.
  4. Hover over the highest point of each currency line and compare the exchange values.

Data Source

Current and historical exchange rate data is provided by the Frankfurter API.
