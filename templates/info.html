About SEK Currency Dashboard

Project description

SEK Currency Dashboard is a web application built with Python and Flask. It allows users to compare the Swedish krona (SEK) with EUR, USD, GBP, NOK and DKK using current and historical exchange rates.

Analysis Guide

Follow the instructions below to answer the analysis questions using the dashboard.

1. How has the value of SEK in EUR changed over the last 12 months?

  1. Enter 1 in the SEK amount field.
  2. Select EUR and click Submit.
  3. Look at the line chart showing the historical exchange rates.
  4. Compare the beginning and end of the line to see whether SEK has increased or decreased in value against EUR.

2. Against which of the five currencies has SEK strengthened or weakened the most over the past year?

  1. Enter 1 in the SEK amount field.
  2. Select all five currencies and click Submit.
  3. Click Switch Chart to display the percentage change bar chart.
  4. Compare the percentage changes to identify where SEK has strengthened or weakened the most.

3. In which of the five currencies has 1 SEK had the highest numerical exchange value during the last 12 months?

  1. Enter 1 in the SEK amount field.
  2. Select all five currencies and click Submit.
  3. Use the line chart and select Day for the most detailed view.
  4. Hover over the highest points of each line to compare their exchange values.

Data source

Exchange rate data is retrieved from the Frankfurter API .
